# SYMMETRY SHIFT

GitHub Pages에 올릴 수 있는 정적 게임 파일입니다. 별도 설치나 빌드가 필요 없습니다.

## 게시 방법

1. GitHub에서 새 저장소를 만들고 이 폴더 안의 파일 5개를 저장소 최상위에 올립니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. Branch는 `main`, 폴더는 `/(root)`로 선택한 뒤 저장합니다.
5. Pages가 표시하는 주소로 접속합니다.

`index.html`, `game.js`, `physics.js`는 같은 폴더에 있어야 합니다. `.nojekyll` 파일은 그대로 함께 올리면 됩니다.

## 조작

- PC: 방향키로 좌우 이동, Alt로 점프합니다.
- 휴대폰·태블릿: 화면 아래의 화살표를 누르고 있으면 이동합니다. 다른 손가락으로 점프를 누르면 대각선 점프가 됩니다.
- 도형을 클릭하거나 터치해 선택한 뒤 대칭 버튼을 누릅니다.
- 가로·세로 화면을 모두 지원합니다. 화면을 회전하거나 앱을 벗어나면 누르고 있던 이동 입력이 해제됩니다.
- 클리어하면 다음 스테이지가 열리고, 새로고침하면 진행도가 초기화됩니다.

기존 버전을 올려두었다면 `index.html`, `game.js`, `physics.js` 세 파일을 모두 교체합니다.
